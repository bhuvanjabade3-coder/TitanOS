# Changelog

## 0.1.0 — unreleased

First working build.

- TITAN Core: action registry with risk gates, approvals, audit log; SQLite
  with migrations; local API token; task engine; notifications and reminders.
- Actions: files, terminal and processes, applications, windows and input,
  browser and bookmarks, memory, security overview, system settings, developer
  tools, voice, plugins.
- AI Core: Claude tool loop over the registry with plan and execute modes.
- TITAN Shell: window manager, workspaces, dock, launcher, notification panel,
  approval dialog and twelve apps; dark/light themes, accents, wallpapers.
- Deployment: user-level installer, systemd user service, launcher, backup and
  restore, Mac-to-VM sync, whisper.cpp setup.

Not yet verified on Ubuntu 24.04 ARM64 or with the live Claude API; see FEATURES.md.
